## 🤖 About the Project

**NandiGen AI** is an AI-powered content generation web application designed to help users create different types of written content from simple prompts.

The project allows users to select a content type, enter a topic or instruction, and prepare a structured AI prompt using a reusable prompt library.

The goal is to develop a practical application that demonstrates how AI can support content creation and improve productivity.
